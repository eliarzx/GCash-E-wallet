# GCash E-Wallet

A GCash-inspired e-wallet desktop application built with Java Swing and Microsoft SQL Server, featuring account management, cash-in, money transfers, loans, and transaction tracking.

## Setup

See [README.txt](README.txt) for the full setup guide and project documentation. Before running, replace `YOUR_DB_USERNAME` and `YOUR_DB_PASSWORD` in the Java connection settings with your local SQL Server credentials. Keep real credentials out of commits.
